# Razorpay Landing Page Clone

A responsive recreation of Razorpay's landing page built with HTML and Tailwind CSS, created to practice modern frontend layout, responsive design, and component-style UI development.

## 🌐 Live Demo

[View Live Website](https://razorpay-clone-azure-five.vercel.app/)

## 🔍 Overview

This project replicates the visual design and layout of Razorpay's homepage, including:

- Responsive navbar with dropdown-style hover effects
- Hero section with call-to-action
- Payment Suite feature section with custom SVG card shapes
- Business Banking feature section
- "New in the Product Suite" cards grid
- Core Features section
- Testimonials/customer quotes carousel layout
- CTA (Call To Action) banner
- Full multi-column footer with newsletter signup, social links, and company info

## 🛠️ Built With

- **HTML5** – page structure
- **Tailwind CSS** – utility-first styling
- **PostCSS** – CSS processing
- **Feather Icons** – lightweight icon set (loaded via CDN)
- **Google Fonts (Mulish)** – typography

## 📁 Project Structure

```
razorpayClone/
```

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine

### Installation

1. Clone the repository
```bash
git clone https://github.com/devsedoc/razorpayClone
cd razorpayClone
```

2. Install dependencies
```bash
npm install
```

3. Build/watch Tailwind CSS (adjust script name based on your `package.json`)
```bash
npm run build
```

4. Open `index.html` in your browser (or use a Live Server extension in VS Code) to view the site.

## ✨Features

- **Fully Responsive Design** – Optimized for desktop, tablet, and mobile screens
